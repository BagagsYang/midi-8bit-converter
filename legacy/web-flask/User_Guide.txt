OCTABIT USER GUIDE

This guide covers the legacy Flask-rendered browser fallback for OctaBit.
Normal production traffic now uses the Vue frontend in `frontend/` with
Flask providing the backend API.

Official site: <https://octabit.cc>

Project layout:
- `frontend/` contains the production browser frontend.
- `legacy/web-flask/` contains the Flask backend API and legacy browser fallback.
- `legacy/native/macos/` contains the deprecated/paused native macOS application for reference.
- `legacy/native/windows/` contains the deprecated/paused native Windows application for reference.
- `legacy/python-renderer/` contains the shared Python synthesis engine.
- `assets/previews/` contains the shared waveform preview WAV files.

==================================================
1. SYSTEM REQUIREMENTS FOR THE WEB APP
==================================================
To run the browser version, you need:
- Python 3.x installed on your computer.
- A repo-local virtual environment in the project root.

Create or refresh the local environment with:
python3 -m venv .venv
./.venv/bin/python3 -m pip install -r legacy/web-flask/requirements.txt

Important:
- Use `./.venv/bin/python3 -m pip`, not the bare `pip` launcher, because moved virtual environments can leave stale entry-point paths behind.

==================================================
2. HOW TO START THE WEB APP
==================================================
For production-style local development, start Flask on port 8000 and run the Vue
frontend from `frontend/`.

The launcher scripts do that for you after Vue dependencies have been installed
with `cd frontend && npm ci`.

1. Double-click `legacy/web-flask/Launch_Synthesiser.command`, or run:
   `legacy/web-flask/Launch_Synthesiser.command`
   On Windows, double-click `legacy\web-flask\Launch_Synthesiser.bat`.
2. Wait for the browser to open `http://127.0.0.1:5173`.
3. Keep the terminal window open while the Vue app is running. On Windows,
   also leave the Flask API window open.

Legacy Flask fallback:
- Run `./.venv/bin/python3 legacy/web-flask/app.py` directly.

==================================================
3. HOW TO USE THE WEB APP
==================================================
- Add MIDI files by clicking the queue import area or dragging `.mid` / `.midi` files into it.
- Reorder queued files with the Move Up / Move Down buttons.
- Remove selected items or clear the whole queue.
- Mix up to 4 waveform layers.
- Preview each waveform layer directly inside the app.
- Choose the sample rate before exporting.
- When you click export, OctaBit processes the queue and downloads each ready WAV file.

Output naming:
- Single-layer export: `<original>_<wave>.wav`
- Multi-layer export: `<original>_mix.wav`

==================================================
4. WAVEFORM GUIDE
==================================================
SQUARE / PULSE:
The classic chiptune sound.
- 0.50 pulse width gives the most familiar square-wave tone.
- Lower pulse widths create thinner, sharper sounds.

SINE:
A pure, smooth tone for softer melodies.

SAWTOOTH:
A bright, buzzy tone that works well for leads and bass.

TRIANGLE:
A softer, hollow tone often used for basslines.

==================================================
6. TROUBLESHOOTING
==================================================
- The browser app fails to start because dependencies are missing:
  Run `./.venv/bin/python3 -m pip install -r legacy/web-flask/requirements.txt`
- Preview audio does not play:
  Confirm the preview WAV files are present in `assets/previews/`.
- No sound in the exported WAV:
  Drum tracks are ignored. Use a MIDI file with pitched instrument notes.
